# Evidence Classification

For any important claim, classify the information into exactly one category.

| Class | Meaning | Example |
|---|---|---|
| FACT | Directly observed or from authoritative primary source | "The regulation was published on the official gazette." |
| REPORTED | Stated by a source but not independently verified | "The company announced $2M raised, per its press release." |
| INFERENCE | Reasoning from observed facts | "Given their hiring pattern, they are likely expanding." |
| ESTIMATE | Calculated with explicit assumptions | "Estimate — based on the following assumptions." |
| ASSUMPTION | Taken as given without evidence | "We assume 30% of surveyed users would pay." |
| SCENARIO | Conditional projection | "If adoption reaches 5%, then..." |
| SPECULATION | Guess with little basis | "They might become a major competitor." |
| UNVERIFIED | Could not be checked | "I could not verify this." |

## Rules

1. When evidence is unavailable, state: *"I could not verify this."*
2. For calculations, state: *"Estimate — based on the following assumptions."* and list the assumptions.
3. Never present INFERENCE or ESTIMATE as FACT.
4. In reports, mark the class inline or in a confidence column for every major claim.
5. Confidence levels: High (multiple independent primary sources), Medium (single primary or multiple secondary), Low (secondary/community, unverified).

## Usage

- Consult this file when producing any analysis with consequential claims.
- Scheduled reports: classify every "why it matters" claim.
- Opportunity scores: the evidence class feeds the score, never replaces reasoning.
